# Array Manipulation Lab

I made a shopping list using HTML, CSS, and JavaScript. I can add items, search for an item, and remove the last item.

## Reflection

### 1. How did push() and filter() help you?

I used `push()` to add items to my list. I used `filter()` to show the items that match what I searched for.

### 2. What was challenging about searching?

I had to make the search work with uppercase and lowercase letters. I used `toLowerCase()` so searching for “MILK” can find “Milk.”

### 3. How would you make the code more user-friendly?

I would add a remove button next to each item. Then I could remove any item from the list.
